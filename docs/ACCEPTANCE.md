## Additional implemented checks

Bill-specific rate/basis and fixed/percentage discounts: exact rounding, invalid/zero basis and excess discount rejection, immutable effective-price snapshots, net-value partial-return conservation, manager approval/capability checks (including cached retries), independent capability updates and review-hash protection against same-total line edits. Browser coverage includes the simplified header/default date, live server amounts and edited-price draft recovery.

Atomic split receipts; classified owner correction/role forgery denial; opening batch dry-run, rollback and row identity; opening borrowing repayment; frozen approval executes once; all report/CSV routes; stale bank reconciliation on reopen; concurrent receipts and refund-dependent return correction; atomic draft consumption; public-registration and forged-Origin denial; persistent cash differences with owner resolution.

Configured document numbering; permission recheck before cached idempotent responses; stale bill review rejection after a balance or price change; restricted PostgreSQL runtime-role posting with financial-history UPDATE denied.

## Live acceptance still requires people and actual devices

- Owner confirmation of real identities, units/rates/conversions, cutover and all signed openings/accounts.
- Accountant review of operational mappings and statutory invoice requirements.
- Independent financial/security code review and a reconciled parallel trial.
- Actual printer/paper, real HTTPS domain/proxy behavior and deployment access checks.
- Approved off-server encryption/destination/retention, recovery targets and an isolated restore of the live configuration.

Optional/unconfigured scope is explicit: no automatic bank verification, stock availability, tax-invoice engine, automatic interest, MFA setup, public signup, native APK or offline financial posting. Legacy bill-item import is disabled; approved opening totals retain unknown age. Current allocation ageing is today-only; historical journal statements remain available. These boundaries do not change the 55 financial rules.
